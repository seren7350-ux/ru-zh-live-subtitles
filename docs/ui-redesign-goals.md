状态：旧 Goal 已暂停；本聊天接续维护。深色三语原生界面已实施，正在完成运行状态、窗口交互及发行构建验收；尚未交付新版安装包。

## 实际观察

检查版本：5263df0 对应的最终 EXE，overlay-demo，无麦克风。查看 General、Appearance、More、Diagnostics 四页，点击字幕主窗复现设置窗仍压在主窗与字幕之上。演示模式没有麦克风与模型控件，正式模式的这些控件须在设计阶段单独纳入；不能以演示页代替完整设置页。

设置页在当前显示条件下约 660×890 像素，很多页面只有少量内容却保留大片空白；浅色标签栏、白色滚动框、深色内容和旧式滑块混搭。控件尺寸与间距缺乏统一，数值在长滑块上方漂移。More 混放显示、位置、文件、重置与快捷键。Stop 与 Exit 同为红色强调，主窗和设置窗重复会话操作，视觉主次不清。字幕工具栏横贯整个窗口并有明显蓝色边线，视觉存在感过强。

层级并非偶发现象：settings_panel.py 使用 transient(root) 并继承 topmost；caption_layer.py 明确把所属对话框保留在文字上方。新交互不能只随意加 lift()/after()，否则可能重现之前的闪烁。

再次核对源码与已观察界面：settings_pages.py 在所有页无条件 pack 垂直 ttk.Scrollbar，未按内容是否溢出显示／隐藏；内容短于视口时没有滚动行程，滑块可能填满轨道而无法辨认。Notebook 与 Scrollbar 未设置应用主题，深色 tk Frame/Canvas 和默认浅色 ttk 控件混用；Canvas 已设置 highlightthickness=0，因此不能把白框一概归咎于 Canvas 焦点边框。外观页使用 tk.Scale，只设置背景／文字颜色，没有统一轨道、滑块、边框和活动态，导致浅轨道与深色短滑块割裂。目标是去掉无语义嵌套框、无溢出不显示滚动条，并明确可辨识的滑块及键盘焦点。

修改范围以 settings_pages.py、settings_panel.py 为主，可增设局部主题模块；主窗外观限于 overlay.py，激活层级限于 window_coordinator.py 与必要的 caption_layer.py 协同。保留设置回调及状态接口，不为纯视觉改进改动识别、翻译、音频、SRT 或进程管线；不预先承诺层级修正只改一行。

## Goal 1：确定布局与窗口交互规格

- 先做可审阅的主窗和设置页设计，包含正式模式的输入设备、模型状态、错误与加载状态。
- 以紧凑的桌面工具为目标，统一字号、颜色、间距、控件高度、焦点与禁用态；减少重边框和空白。
- 设置分为“输入与运行”“字幕外观”“窗口与保存”；模型详细信息、日志和排障收进“高级／诊断”。具体页数随内容密度调整，不保留泛泛的 More。
- 定义层级：显式打开设置时设置前置；用户点击字幕时主窗和文字作为整体前置，设置不抢回焦点；再点设置可恢复。关闭设置不停止字幕。
- 分开定义“字幕对其他应用置顶”和“应用内部哪个窗口前置”。两者不能由一个永久 owner 顺序替代。
- 验收：所有现有功能有明确去处；设计包含正常、错误、零透明度、工具栏隐藏状态，不靠删功能简化界面。

## Goal 2：修正窗口激活与层级

- 通过现有 WindowCoordinator 集中处理主窗／文字／设置的激活策略；评估设置窗 owner 与 topmost 的使用方式。
- 文字层仍随主窗移动且不抢焦点；避免每帧抬窗、反复 focus/lift 和 Configure 反馈循环。
- 字幕完全透明或工具栏隐藏时，仍能从任务栏／设置入口恢复操作。
- 验收：主窗与设置轮流点击、跨应用切换、开启／取消置顶、无边框切换、最小化恢复、单实例唤回、关闭与退出均符合规格；重叠时不持续闪烁、不丢窗口。

## Goal 3：实现设置界面

- 使用一致的主题控件与紧凑分组，调整默认窗口尺寸，窗口大小受工作区约束。
- 滑块采用“名称＋固定位置数值＋轨道”，百分比和字号单位明确，键盘可操作；滚动条仅在内容实际溢出时出现。
- 统一主次按钮；退出不与常规操作争夺注意力；运行状态与取消／停止入口明确，避免无意义重复。
- 技术说明默认收起；保留模型就绪状态和可执行的错误指引。
- 验收：各页布局连贯，无大片无效空白、裁切或遮挡；常用操作无需在多个无关页间跳转。

## Goal 4：整理字幕窗口视觉

- 弱化工具栏和装饰边线，缩小视觉噪声；字幕保持主体地位。
- 统一设置与主窗的色彩、按钮和状态表达；保持拖动命中区与边缘缩放可用，不恢复“Drag”提示。
- 保留俄中各一行、只在溢出时跑马灯、双击底栏、独立透明度至 0 和黑描边。

## Goal 5：回归与发行验收

- 用短句／长句演示和实际模型加载验证；覆盖窗口层级、连续重叠、拖动缩放、键盘、零透明度恢复、SRT、错误日志及资源释放。
- 至少覆盖当前 144 DPI、小工作区和正常工作区；跨显示器 DPI 仍记录为硬件限制，不能写成已通过。
- 每阶段独立提交可回滚；保留现有已验收安装包。UI 与交互稳定后才重建最终 EXE／分卷安装器，再验收默认启动和离线部署。
