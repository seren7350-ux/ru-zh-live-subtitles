RUSSIAN-CHINESE LIVE SUBTITLES 0.3.0 - MODEL SETUP
=================================================

The self-contained CPU offline installer contains all required pinned model
weights and does not download models. Setup automatically installs the managed
model layout. No Python, token, network connection, or manual copy is required.

Target model root:
  %LOCALAPPDATA%\ru-zh-live-subtitles\models

Required assets:
  Silero VAD 6.2.1
  ai-sage/GigaAM-Multilingual
    variant large_ctc
    revision 3905cd51c3ed4e88c8edf33f3302969ba480a327
  facebook/nllb-200-distilled-600M
    revision f8d333a098d19b4fd9a8b18f94170487ad3f821d

Optional developer-only legacy asset (not included by this installer):
  istupakov/gigaam-v3-onnx
    revision 322c3b29492673eb7d0b434bfa9dfb8653e34d02

Run from the installed application directory:
  ru-zh-subtitles-console.exe model-doctor

The expected result is "Offline readiness: READY". A missing legacy RNNT cache
may appear as an optional warning and does not make readiness fail. Offline mode
sets only process-local HF_HUB_OFFLINE and TRANSFORMERS_OFFLINE values; it does
not change system or user environment variables and never downloads assets.

Large CTC and NLLB use significant memory: 8 GiB RAM is the minimum and 16 GiB
is recommended. NLLB is CC-BY-NC-4.0 and restricted to non-commercial use.

Uninstalling removes the application, all offline models, logs, caches, and
other application-owned data. Reinstall the complete model assets before using
the application again.
