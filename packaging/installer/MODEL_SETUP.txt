RUSSIAN-CHINESE LIVE SUBTITLES - MODEL SETUP
================================================

The self-contained CPU offline installer contains all pinned model weights and
does not download models. Setup automatically installs and verifies the managed
model layout. No Python, token, network connection or manual copy is required.

Target model root:
  %LOCALAPPDATA%\ru-zh-live-subtitles\models

Required assets:
  Silero VAD 6.2.1
  istupakov/gigaam-v3-onnx
    revision 322c3b29492673eb7d0b434bfa9dfb8653e34d02
  facebook/nllb-200-distilled-600M
    revision f8d333a098d19b4fd9a8b18f94170487ad3f821d

Run from the installed application directory:
  ru-zh-subtitles-console.exe model-doctor

The expected result is "Offline readiness: READY". Offline mode sets only
process-local HF_HUB_OFFLINE and TRANSFORMERS_OFFLINE values; it does not change
system or user environment variables and it never downloads missing assets.

NLLB-200 distilled 600M uses CC-BY-NC-4.0 and is restricted to non-commercial
use. This project remains a local research/non-commercial candidate.

Uninstalling the application preserves the model directory. To reclaim the
approximately 3.4 GB used by model assets, delete that directory manually after
you no longer need it.
